🛡️ CyberSafe

Secure Reporting. Faster Response.

About the Project

CyberSafe is a cybersecurity project focused on helping women report online image abuse, unauthorized photo sharing, and misuse of personal photographs.

Current Features

- Basic Flask application
- Homepage route
- Local development server

Planned Features

- Secure user registration and login
- Cybercrime complaint submission
- Secure evidence management
- Complaint status tracking
- Authorized officer dashboard
- AI-assisted complaint classification

Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- MySQL

Project Status

🚧 Currently under development.
